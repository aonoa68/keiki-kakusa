# 景気・格差問題と統計情報

*Business Indices, Disparities and Statistics*

立教大学で2022〜2025年度に担当した授業の資料です。ここに置いているのは主に **2025年度** の版です。

## この授業について

「景気」や「格差」という言葉が指す内容を、公的統計を使って実態としてとらえる方法を学ぶ授業です（サブタイトルは「経済統計入門1」）。人口・労働・賃金・消費の各テーマについて、e-Stat などから政府統計を入手し、グラフや指標を自分で作って読み解きます。演習では Google Colaboratory（Python）と Excel を使い、移動平均、従属人口指数、ヒストグラム、ローレンツ曲線とジニ係数などを実際に計算します。

| | |
|---|---|
| **大学** | 立教大学 |
| **開講** | 全学共通科目・全学共通カリキュラム（総合系）／多彩な学び ／ 秋学期 |
| **担当年度** | 2022〜2025年度 |
| **使用ツール** | Python（Google Colab）、Excel、e-Stat、jSTAT MAP、RESAS／RAIDA、生成AI（ChatGPT など） |

全14回のうち第1・5・7・9・11・13・14回が教室での対面回、第2・3・4・6・8・10・12回はオンデマンド動画による自習回でした。動画回の教材は他の教員が作成したもののため、このサイトには対面回（ガイダンス・演習・まとめ）の資料だけを掲載しています。
