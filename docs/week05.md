# 第5回　データへのアクセス演習

政府統計の総合窓口 e-Stat、統計GIS（jSTAT MAP）、RESAS・RAIDA の使い方を確認し、jSTAT MAP で統計地図を作成します。後半は Google Colaboratory と Python で家計調査の消費支出の12か月移動平均と前年同月比を計算し、グラフにします。
