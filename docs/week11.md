# 第11回　賃金統計演習

賃金構造基本統計調査・毎月勤労統計調査へのアクセス方法を確認し、集団間の賃金格差をヒストグラムと平均値・中央値などの統計指標で読み解きます。Excel と Google Colaboratory でのヒストグラムの描き方も扱います。
